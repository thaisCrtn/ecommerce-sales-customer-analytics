# 🇬🇧 English

## 📊 About the Project

This project aims to analyze e-commerce sales, customer behavior, and product performance using SQL.

The analysis is based on business questions designed to identify sales patterns, customer purchasing behavior, top-performing products, and revenue trends over time.

The main goal is to demonstrate practical SQL and data analytics skills in a business-oriented scenario similar to those encountered by Junior Data Analysts.

---

## 🎯 Objectives

The main objectives of this project are to:

- Analyze overall sales performance;
- Identify the top customers by revenue;
- Identify the best-performing products and categories;
- Analyze monthly revenue trends;
- Calculate monthly revenue growth;
- Identify returning customers;
- Compare performance across different periods;
- Use SQL to answer business questions;
- Apply basic, intermediate, and advanced SQL techniques.

---

## ❓ Business Questions

### Customer Analytics

- Who are the top customers by revenue?
- How many orders does each customer make?
- Which customers are returning customers?
- What percentage of customers have made more than one purchase?

### Product Analytics

- What are the best-performing products?
- Which categories generate the most revenue?
- Which products have the highest number of orders?
- What are the top 3 products within each category?

### Sales Analytics

- What is the total revenue?
- What is the monthly revenue?
- What is the monthly revenue growth?
- Which month had the highest revenue?

# 🇧🇷 Português

# E-commerce Sales & Customer Analytics

## 📊 Sobre o projeto

Este projeto tem como objetivo analisar dados de vendas, clientes e produtos de um e-commerce utilizando SQL.

A análise será orientada por perguntas de negócio, buscando identificar padrões de vendas, comportamento dos clientes, desempenho dos produtos e evolução da receita ao longo do tempo.

O projeto também tem como objetivo demonstrar conhecimentos de SQL aplicados a um cenário próximo ao encontrado no mercado de trabalho para uma posição de Junior Data Analyst.

---

## 🎯 Objetivos

Os principais objetivos deste projeto são:

- Analisar o desempenho das vendas;
- Identificar os clientes com maior receita;
- Identificar os produtos e categorias com melhor desempenho;
- Analisar a evolução mensal da receita;
- Identificar clientes recorrentes;
- Comparar o desempenho entre diferentes períodos;
- Utilizar SQL para responder perguntas de negócio;
- Praticar consultas SQL básicas, intermediárias e avançadas.
